## 2026-10-24 — 관리자 ZIP 용량 제한 보완 (2단계 적용)

- `data/history.json`의 임의적인 파일당 2MiB 검사 제한을 관리자 브라우저 및 Cloudflare Worker 양쪽에서 제외함.
- 악의적인 압축 해제/실수 업로드 방지를 위해 전체 허용 파일의 압축 해제 크기 16MiB 제한을 유지하고, 다른 개별 파일은 기존 2MiB 검사 유지. ZIP 자체 20MiB 제한 유지.
- ZIP 검사 시점부터 용량 오류를 표시하여 커밋 직전에만 실패하던 문제도 예방.

- **순서:** 1단계 관리자 제한 패치 GitHub 커밋 → Cloudflare Worker 새 버전 배포 확인 → 2단계 v25 연혁 통합 데이터 패치 업로드. Worker가 구버전이면 2단계 요청이 여전히 413 오류로 거부될 수 있음.
- GitHub 커밋이 Cloudflare Worker 배포까지 완료됐다는 의미는 아님. 관리자 배포 상태에서 Worker 버전 변경을 확인할 것.
- 이전 2MiB는 사이트 원본의 관리자 배포 처리 로직에 하드코딩된 검증 정책이며, `history.json`의 파일 포맷 규칙은 아님.
