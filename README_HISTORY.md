# 활동 연표 출처 조사 및 호버 표시 개선 (2026-10-23)

- 데이터 기준: 기존 중복 통합본 1,958개 **공개 일정**을 유지. 원본 일정의 ID/제목/추천영상 및 기존 검증 링크는 삭제하지 않음.
- JTBC 《신화방송》 공식 다시보기 목록으로 1~43회 방송일/회차를 대조하고, 59~60회와 `작은 신화` 일부 회차도 대조. **방송 내용 전체**나 개별 촬영 날짜를 검증한 것은 아님.
- 2012년 22회는 JTBC **2012-08-11**, 영문 위키백과 **2012-08-12** 충돌 → 공식 JTBC 우선(기존 일정은 8월 11일이므로 유지).
- 2013년 `작은 신화` 6회는 JTBC 같은 페이지 상단 **2013-12-08**, 본문 **12월 15일** 충돌. 기존 연표 2013-12-15 보존하며 `공식 기록 내부 날짜 충돌`과 근거를 표시. 확정 변경 금지.
- 벅스 음반 상세 정보로 2013 THE CLASSIC, 2015 WE, 2016 UNCHANGING Part 1, 2017 TOUCH의 정확히 일치하는 *음반 발매/음원 공개 행*만 상태 승격. 같은 날짜의 방송·MV·팬사인회 등과는 혼합하지 않음.
- 신화 20주년 팬파티(KBS World), 2017년 콘서트 예고(조선일보 중국어판)는 *예정 보도*로만 연결, 실제 개최 확인으로 승격하지 않음.
- 조사 자료 링크: JTBC 공식, 벅스 음반, 일본 음반사, 일본어/중국어 위키, 해외 팬 공연 연표 등 총 **46건** (개별 이벤트가 연결되지 않은 참고자료는 개별 일정의 증거처럼 붙이지 않음).
- PC ⓘ 패널은 `document.body`에 하나의 `position:fixed` 레이어로 표시. 기존 행의 `z-index`/overflow/stacking context에 가려지지 않으며 팝업 내부 링크 클릭 가능. 모바일은 하단 고정 레이어.
- 관리자/Worker, 기존 영상 데이터, 추천영상 점수/링크/승인 상태 및 Chapter는 수정하지 않음.
- 마지막 검증: JS 문법, ZIP 무결성, 브라우저 컴퓨터/모바일 hover·click·Esc·링크·필터 정상 작동 확인 필요.

# 중복 통합 · 영상 추천 정확도 개선 (2026-10-23)

- 같은 날짜·방송사·프로그램(회차), 팬클럽 동일 기수 행사, 동일 음반 발매 등의 *동일 사건*만 통합했습니다. 서로 다른 방송과 독립 뮤직비디오·앨범 발매는 동일 날짜여도 별도 유지합니다.
- 원본 2,071행 중 113개의 중복 원본 행을 병합하여 공개 일정 1,958건을 생성했습니다. 110개 사건 묶음이 생성되었고 병합된 원본 ID/제목/링크/검증 근거는 `history.json`의 `mergedRecordIds`, `mergedDetails`, `sourceUrls`, `verificationUrls`, `sourceRefs`에 보존됩니다.
- 예시: 신화창조 1기(1998-10-25), 정규 2집(1999-04-15), 음악캠프 E005(1999-06-12), 음악캠프 E007(1999-06-26) 중복 통합 확인.
- 2000년 신화창조 3기 팬미팅은 5/20·5/21 원문을 같은 사건으로 묶되 날짜 충돌 표기를 유지하며 5/21을 대표 날짜로 사용합니다. 이는 공식 개최일 최종 검증을 의미하지 않습니다.
- **추천 영상:** 유튜브 원본 메타데이터 기준 **일자까지 식별되는 단일 날짜** 및 같은 연월을 우선합니다. 프로그램·회차/곡명 또는 고유 행사명 정합성이 있어야 하며 규칙 기반 점수 **70점 이상**만 후보로 표시합니다. 다중 날짜 편집 영상, 설명에 여러 공연 날짜가 열거된 영상, 같은 날짜만 맞는 영상은 제외합니다.
- V LIVE 종료 링크는 출처 및 추천에서 제거합니다. V LIVE 당시 방송 일정 자체는 기록으로 보존합니다.
- 1,958개 일정 중 9개 일정에 유튜브 추천 12건을 확인했습니다. 이는 자동 유사도 **조건 충족 후보**이지, 해당 촬영·방송을 독립적으로 검증한 결과가 아닙니다.
- 기존 영상 원본 655개, 관리자/Worker API, 아카이브 메인화면은 수정하지 않습니다. 이전 `?event=원본ID` 링크는 `metadata.legacyEventAliases`를 통해 병합 일정으로 이동합니다.

# 출처 호버 및 기록 근거 구분 (2026-10-23 업데이트)

- 각 일정 옆 **ⓘ**: 마우스 올리기·키보드 포커스·클릭/터치로 출처 팝오버 표시. 검증 기사/음반정보/보조 위키/원문 시트를 서로 구분하며, 실제 URL이 없는 기록은 그 사실을 표시합니다.
- 상단 안내의 작은 **ⓘ 조사 자료**에는 그동안 확인·대조한 공개 레퍼런스 URL을 모았습니다. 모든 출처가 모든 일정의 검증 근거라는 뜻은 아닙니다.
- 1996년 4월 신혜성 첫 합류 주장은 공식/동시대 근거로 확인되지 않아 공개 연표에서 제외. 2004년 5월 21일 디지털 싱글 발매 주장도 벅스 발매일과 일치하지 않아 공개 연표에서 제외하고 2004년 8월 30일 음반 발매일을 새로 수록했습니다. 두 원문 행과 제외 사유는 `data/history.json`의 `metadata.excludedFromPublicTimeline`에 보존합니다.
- 팬 연표에서 가져온 문장은 URL을 표기해도 날짜 검증 완료를 뜻하지 않습니다. 제한된 구글 시트의 외부 복사·다운로드 차단 여부는 그대로 유지됩니다.
- 2019년 4월 20~21일 21주년 콘서트 행은 당시 YTN 현장 보도와 매일경제 개최 기사를 근거로 검증 상태를 상향했습니다.
- 기존 JSON 형식, 관리자/Worker, 영상 데이터와 양방향 날짜 이동 기능은 유지했습니다. 캐시 갱신을 위해 history.* 쿼리 버전을 바꿨습니다.

# 활동 연표 Chapter 1~4 통합 및 검증 분류 (2026-10-23)

## 데이터
- `data/history.json`에 2,067개 기존 통합 원본 기록 + 동시대 신문 기사로 직접 근거가 있는 전환 기록 5건 = **2,072개 기록 행**을 반영했습니다. 중복 기록은 원본 보존을 위해 자동 삭제하지 않았고 `possibleDuplicate`로 표시했습니다.
- Chapter 1: 2003-05-08까지, 데뷔 준비(1996~97) 예외 포함. Chapter 2: 2003-05-09~2011-06-30, 2003년 5~7월 소속사 전환기 포함. Chapter 3: 2011-07-01~2018-12-31. Chapter 4: 2019-01-01 이후. 이 구간은 '신화 그룹 활동사의 시대 구분'이며 개인 멤버의 각 소속사를 뜻하지 않습니다.
- 확인된 동시대 기사: 2003-05-01 SM 재계약 결렬 보도, 2003-06-12 계약 관련 보도, 2003-07-14 GOOD 관련 보도, 2011-07-01 설립일(8월 보도), 2011-08-01 설립 발표.
- 각 행별 `verification`, `verificationUrl`, `sourceUrl`, `dateKind`를 분리했습니다. `sourceUrl`이 구글 시트 원본 행이라면 **독립적 사실 검증의 증거가 아닙니다**. 파일 안의 링크가 공개 웹에서 열리지 않을 수 있습니다.
- 현재 사이트에서 확인되는 실제 개별 자료는 2020년까지입니다. 2021년 이후 기록을 만들어 넣지 않았습니다.
- 일부 동시대 자료도 같은 행사 날짜를 다르게 표기하므로 1999년 드림콘서트(5/15 vs 5/18), 1998 으쌰으쌰 촬영 등은 `날짜 충돌`로 보존했습니다.
