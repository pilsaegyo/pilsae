# 활동 연표 Chapter 1~4 통합 및 검증 분류 (2026-10-23)

## 데이터
- `data/history.json`에 2,067개 기존 통합 원본 기록 + 동시대 신문 기사로 직접 근거가 있는 전환 기록 5건 = **2,072개 기록 행**을 반영했습니다. 중복 기록은 원본 보존을 위해 자동 삭제하지 않았고 `possibleDuplicate`로 표시했습니다.
- Chapter 1: 2003-05-08까지, 데뷔 준비(1996~97) 예외 포함. Chapter 2: 2003-05-09~2011-06-30, 2003년 5~7월 소속사 전환기 포함. Chapter 3: 2011-07-01~2018-12-31. Chapter 4: 2019-01-01 이후. 이 구간은 '신화 그룹 활동사의 시대 구분'이며 개인 멤버의 각 소속사를 뜻하지 않습니다.
- 확인된 동시대 기사: 2003-05-01 SM 재계약 결렬 보도, 2003-06-12 계약 관련 보도, 2003-07-14 GOOD 관련 보도, 2011-07-01 설립일(8월 보도), 2011-08-01 설립 발표.
- 각 행별 `verification`, `verificationUrl`, `sourceUrl`, `dateKind`를 분리했습니다. `sourceUrl`이 구글 시트 원본 행이라면 **독립적 사실 검증의 증거가 아닙니다**. 파일 안의 링크가 공개 웹에서 열리지 않을 수 있습니다.
- 현재 사이트에서 확인되는 실제 개별 자료는 2020년까지입니다. 2021년 이후 기록을 만들어 넣지 않았습니다.
- 일부 동시대 자료도 같은 행사 날짜를 다르게 표기하므로 1999년 드림콘서트(5/15 vs 5/18), 1998 으쌰으쌰 촬영 등은 `날짜 충돌`로 보존했습니다.
- 참고: 2,072는 서로 다른 행사 수가 아닌 **원본 기록 행 수**입니다. 전체 2,072건을 각각 방송사·신문사로 독립 검증한 것은 아닙니다.

## 영상
- 기존 동일 날짜 후보 연결은 유지합니다. `videos.json`의 저장된 날짜 또는 설명에 실제로 기재된 날짜만 사용하고, 촬영일·방송일·업로드일을 같다고 간주하지 않습니다.
- 정확히 같은 행사인지 확인되지 않은 같은 날짜 영상은 미확정 후보로 명시합니다.
- 관련 영상 추천은 향후 `data/history.json`의 개별 사건에 `relatedVideos: [{"videoId":"유튜브ID","kind":"관련 영상","reason":"연결 검증 근거","reviewStatus":"approved"}]`처럼 명시적으로 승인된 경우에만 출력됩니다. **미승인 523개 후보는 운영 사이트에 '확정 추천영상'으로 노출하지 않습니다.**
- 기존 `data/videos.json` 및 사용자 영상 카드/연도 필터/관리자/Worker 코드는 변경하지 않았습니다.

## 배포 / 체크
- 기존에 확장된 관리자·Worker 배포 허용 목록을 사용하는 사이트 기준입니다. 기존 배포 탭에서 이 ZIP 하나만 업로드하세요.
- 변경 파일 경로: `history.html`, `history.css`, `history.js`, `data/history.json`, `README_HISTORY.md`, `HISTORY.md`.
- 배포 후 `/history.html`에서 Chapter 네 카드, 총 2,072행, Chapter 1~4 개수 742 / 735 / 540 / 55, 2019~2020 기록, 2003 전환기, 2011 신화컴퍼니 기념 기록, `?date=2004-12-10`, 모바일 필터와 더보기 확인.
- 알려진 제한: 시트 행 자체의 실제 방송·촬영·게시 날짜를 완전 검증한 것은 아닙니다. 수동 승인 없이 제목·가까운 날짜만으로 자동 관련영상 확정은 하지 않습니다.
