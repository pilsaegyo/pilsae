# 활동 연표 초기 구현 (2026-10-23)

- 기존 공개 아카이브 헤더에 `활동 연표` 링크 추가.
- `history.html` 별도 페이지와 `history.css`, `history.js` 추가.
- `data/history.json`은 사용자가 제공한 두 중국어 팬 연표를 바탕으로 선별한 **초기 일정 60건**이며, 전체 검증 완료 데이터가 아닙니다. 연표 전체를 아직 전수 반영하지 않았습니다.
- `data/videos.json`에 저장된 **일 단위 날짜(`precision=day`)**만 매칭해 같은 날짜 영상 후보로 표시. 영상 업로드일, 제목 속 날짜 또는 연/월만 적힌 날짜로 연결하지 않음.
- 같은 날짜라는 이유만으로 동일 행사 영상으로 확정하지 않음. 관리자 자동 동기화/Worker/기존 영상 데이터 및 필터 로직은 변경하지 않음.
- 영상 카드 역방향 일정 아이콘/일정별 수동 승인 기능은 아직 구현하지 않음.
- 배포: 변경 파일만 기존 경로에 덮어쓴 후 기존 방식으로 배포. `history.html`이 404가 아닌지, 모바일 헤더와 1998/2004 필터가 동작하는지 테스트.
