# 필새 영상 아카이브 — 날짜 자동 재분석 버전

`videos.json` 원본을 매번 그대로 읽은 뒤 `description + source + title` 전체를 다시 분석하여 날짜를 추출합니다.

## 인식 형식
- `150227` → 2015-02-27
- `010826` → 2001-08-26
- `20010812` → 2001-08-12
- `2015.02.27`
- `2015-02-27`
- `2015/02/27`
- `2015년 2월 27일`
- `2000.06` → 화면에는 2000.06, 내부 정렬값은 2000-06-01
- `2000년 6월` → 화면에는 2000.06
- `00\`` → 화면에는 2000년, 내부 정렬값은 2000-01-01
- `99\`` → 화면에는 1999년
- `1999\`` → 화면에는 1999년
- `99년도`, `1999년` → 연도만 적용

## 2자리 연도 변환 규칙
- 00~29 → 2000~2029
- 30~99 → 1930~1999

## 연도/월만 있는 값 처리
실제 월/일을 알 수 없으므로 화면에는 없는 날짜를 만들지 않습니다.
정렬 및 연도 필터를 위해 내부값만 다음처럼 임시 처리합니다.
- 연도만: YYYY-01-01
- 연/월만: YYYY-MM-01

## 혼합 영상
한 설명에서 2개 이상의 날짜가 추출되면 자동으로 `혼합 영상`으로 분류합니다.

## 정렬
1. 원본/설명에서 얻은 날짜 기준 내림차순
2. 같은 날짜면 YouTube 업로드 날짜 기준 내림차순


## AI 영상 리스트 제외
사이트 표시 단계에서 제목에 아래 문구가 포함된 영상은 자동 제외합니다.
- `Ai 데뷔초 신혜성`
- `Ai 신혜성`

대소문자는 구분하지 않습니다. 따라서 `AI 신혜성`, `ai 신혜성`도 제외됩니다.

원본 `data/videos.json`은 수정하지 않습니다.


## 날짜 표시 정리 규칙
- `99\``, `00\``, `1999\`` 같은 연도만 추정되는 형식은 자동 날짜로 만들지 않음 → `날짜 미확인`
- `2000.06`처럼 일자가 없는 값도 자동 날짜로 만들지 않음 → `날짜 미확인`
- 정확한 날짜 형식만 인식:
  - `150227`
  - `20010812`
  - `2015.02.27`
  - `2015-02-27`
  - `2015/02/27`
  - `2015년 2월 27일`
- `1998-10-25 · 19981025`처럼 같은 날짜가 중복 추출돼도 화면에는 `1998-10-25` 한 번만 표시
- 여러 날짜가 있어도 같은 연도라면 화면에는 그 연도에서 최신 날짜 1개만 표시
- 서로 다른 연도가 여러 개면 연도별 1개씩 표시하며 `혼합 영상`으로 분류


## 날짜 추출 범위 변경
날짜는 이제 **동영상 description 필드에서만** 추출합니다.

다음 값은 날짜 판별에 사용하지 않습니다.
- `title`
- `source`
- YouTube 업로드일 `publishedAt`

따라서 제목에 `1999`, `2001`, `2015` 등이 들어 있어도 설명에 해당 날짜가 없으면 날짜로 인식하지 않습니다.


## 부분 날짜 지원
날짜는 여전히 `description`에서만 추출합니다.

추가 인식:
- `2000.06` → 화면에 `2000.06`
- `2000년 6월` → 화면에 `2000.06`
- `1999년` → 화면에 `1999년`
- `2002년` → 화면에 `2002년`

정렬을 위해 내부적으로는:
- 연도만: `YYYY-01-01`
- 연/월: `YYYY-MM-01`

화면에는 임의의 월/일을 표시하지 않습니다.

같은 연도에서 여러 값이 잡히면 1개만 표시하며,
정확도가 높은 값을 우선합니다:
정확한 날짜 > 연월 > 연도


## 카드형 / 목록형 보기 전환
검색 결과 우측에 보기 전환 버튼을 추가했습니다.

- `▦` : 기존 카드형 보기
- `☰` : 목록형 보기

목록형에서는:
- 작은 썸네일
- 영상 제목
- 날짜

만 간결하게 표시합니다.

선택한 보기 방식은 브라우저 localStorage에 저장되어 다음 방문에도 유지됩니다.


## 해시태그 날짜 제외
날짜 분석은 `description`에서만 수행하며,
`#`로 시작하는 해시태그 토큰은 분석 전에 제거합니다.

예:
- `#1999` → 날짜 인식 안 함
- `#2000년` → 날짜 인식 안 함
- `#2015-02-27` → 날짜 인식 안 함
- 일반 본문 `2015-02-27` → 날짜 인식함

- 기본 파비콘은 `assets/favicon-p.png`(연보라 배경 + 흰색 P)입니다.

## v7 통합 개선
- 혼합영상은 서로 다른 연도가 2개 이상일 때만 분류함. 같은 연도 내 여러 날짜는 해당 연도 영상으로 유지함.
- 같은 연도 날짜는 연도를 반복하지 않고 압축 표시하며, 많은 날짜는 `+N개`로 접어둠.
- 혼합영상은 먼저 연도 요약을 보여주고 세부 날짜를 펼쳐볼 수 있음.

- 제목/설명/출처/날짜 모두 검색 대상임.
- 활성 필터 칩과 개별 해제 기능 추가.
- 결과 영역에서 `전체 N개 · 현재 결과 N개`를 명확히 구분함.
- 모바일은 헤더 통계를 전체 영상 하나만 남기고 더 압축함.
- 관리자 화면에 날짜 미확인 영상 전용 검토 목록, 미확인 사유, 설명 미리보기, YouTube 원본 링크 추가.

- 날짜 더보기 버튼은 연도 요약과 별개로 실제 숨겨진 날짜 개수만 표시.

## v8.1 날짜 정확도별 아카이브 그룹화
- `day`: 정확한 날짜의 해당 월에 배치.
- `month`: 해당 월에 배치하고 `일자 미상` 표시.
- `year`: 1월로 넣지 않고 해당 연도 하단의 `연도만 확인` 영역에 배치.
- `unknown`: 전체 아카이브 마지막의 `날짜 미확인` 영역에 배치.
- 연도만 있는 영상은 내부적으로 YYYY-01-01을 저장해도 화면 그룹화는 `precision` 기준으로 처리하므로 1월 영상으로 오해되지 않음.

## v10 날짜 인식 개선
- `08.11.08`, `08-11-08`, `08/11/08` 같은 `YY.MM.DD` 형식을 정확한 날짜로 자동 인식.
- `9905` 같은 4자리 `YYMM`은 자동 적용하지 않음. 설명의 한 줄 맨 앞에 있고 MM이 01~12일 때만 관리자 `날짜 후보`로 제시.
- 관리자가 `1999.05로 적용`을 누르면 Worker가 GitHub `data/videos.json`에 수동 월 날짜를 저장하고 재배포.
- `날짜 아님`을 누르면 해당 후보를 제외 목록에 저장해 다음 동기화 이후에도 다시 제안하지 않음.
- 수동 적용 날짜와 제외 후보는 YouTube 전체 동기화 시에도 보존.


## v10.1 제목 + 설명 날짜 후보
- 날짜 미확인 영상에 한해 제목도 관리자 검토 후보 탐색에 사용.
- 제목 `08.11.08 ...` → `2008.11.08` 후보(자동 확정 아님).
- 제목 `081108 ...` → `2008.11.08` 후보.
- 제목 `9905 ...` → `1999.05` 후보.
- 설명의 `YY.MM.DD`는 기존처럼 자동 확정.
- 설명의 `YYMM` 4자리는 보수적으로 줄 맨 앞에서만 월 후보 생성.
- 관리자 화면에 `제목에서 발견` / `설명에서 발견` 배지 표시.
- 제목에서 나온 날짜는 반드시 관리자가 `적용`해야 실제 아카이브 날짜가 됨.


## v11 수동 날짜 + 플레이리스트
- 제목이 `2007 콘텐츠명`처럼 4자리 연도로 시작하면 `2007년` 후보로 처리. `2020.07`처럼 YYMM으로 오해하지 않음.
- 관리자 날짜 검토에서 날짜 후보가 없어도 직접 `2007`, `2007.05`, `2007.05.21` 형식으로 입력해 적용 가능.
- 콘텐츠 유형을 날짜 분류와 독립된 `일반 영상 / 플레이리스트`로 추가.
- 관리자에서 모든 영상을 검색해 플레이리스트로 지정/해제 가능.
- 연도가 있는 플레이리스트는 해당 연도/월 아카이브에도 표시되며 플레이리스트 필터로도 별도 탐색 가능.
- 날짜 없는 플레이리스트는 `날짜 미확인`이 아니라 아카이브의 `플레이리스트 > 연도 미지정`에 별도 표시.
- 전체 동기화 후에도 수동 날짜, 날짜 후보 제외 설정, 플레이리스트 지정이 유지됨.


## v12 다중 연도 + 플레이리스트 후보 축소

- 관리자 상단에 `일반 아카이브 보기` 바로가기 추가.
- 콘텐츠 분류 영역의 검색/설명/목록 배치를 정리해 버튼과 설명이 겹치지 않도록 개선.


## v14 다년도 플레이리스트
- 플레이리스트에 `다년도` 범위를 별도로 저장 가능.
- 날짜가 없어도 관리자가 `다년도로 지정`하면 `연도 미지정`/날짜 검토 대상에서 제외.
- 날짜가 실제로 2개 이상의 서로 다른 연도를 포함하는 플레이리스트도 자동으로 다년도 취급.
- 타임라인에 `플레이리스트 > 다년도 플레이리스트` 영역을 별도 표시.
- 진짜 연도를 정할 수 없는 전체 모음만 `플레이리스트 > 연도 미지정`에 남김.
- 관리자 날짜 검토 카운트에는 일반 영상의 날짜 미확인만 집계.
- 콘텐츠 분류 탭의 플레이리스트 항목에서 `다년도로 지정 / 연도 미지정` 선택 가능.
- 동기화 후에도 playlistScope 값 유지.


## v14.1 기존 날짜가 있는 다년도 플레이리스트
- 이미 `2001` 등 단일 날짜가 저장된 플레이리스트도 `다년도로 지정` 가능.
- `playlistScope = multi-year`가 기존 대표 날짜보다 우선하도록 변경.
- 따라서 기존 날짜를 삭제하지 않아도 타임라인에서는 `플레이리스트 > 다년도 플레이리스트`로 이동.
- 관리자 콘텐츠 분류 목록에서 기존 대표 날짜가 남아 있는 경우 참고용으로 표시.


## v14.2 콘텐츠 분류 버튼/UI 정리
- 관리자 `콘텐츠 분류` 탭에 아이콘 추가.
- `플레이리스트로 지정`, `다년도로 지정`, `연도 미지정`에 각각 독립 아이콘과 텍스트 표시.
- 기존 버튼들이 한 줄/좁은 열에서 겹치던 레이아웃을 카드별 하단 액션 영역으로 분리.
- 태블릿/모바일에서는 액션 영역을 영상 정보 아래 전체 너비로 이동.
- 작은 모바일에서는 다년도/연도 미지정 버튼을 자동으로 한 줄씩 배치.


## v14.3 수동 날짜 이후 설명 변경 감지
- 수동 날짜가 지정된 영상의 YouTube 설명이 수정되면 다음 API 동기화에서 변경을 감지.
- 기존 수동 날짜는 `previousManualDates`로 보관하고 활성 날짜에서 잠시 제외.
- 새 설명에 날짜가 있으면 그 날짜를 우선 표시.
- 새 설명에 날짜가 없으면 다시 `날짜 검토` 대상으로 이동.
- 관리자에서 이전 수동 날짜와 새 설명에서 인식된 날짜를 함께 확인 가능.
- `새 설명 날짜 사용` 버튼으로 새 설명 기준을 확정 가능.
- 새 수동 날짜를 다시 입력하면 검토 상태가 자동 해제됨.
