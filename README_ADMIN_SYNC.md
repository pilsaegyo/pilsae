# 필새 영상 아카이브 — 관리자 자동 동기화 버전

이 패키지는 공개 사이트 + 별도 Cloudflare Worker 관리자 API로 구성됩니다.

## 구조

- `index.html`
- `style.css`
- `script.js`
- `site-config.json`
- `data/videos.json`
- `worker/index.js`
- `worker/wrangler.jsonc`

## Worker가 하는 일

1. YouTube `channels.list`에서 `@pilsae` 채널을 찾음
2. 채널의 uploads playlist ID 확인
3. `playlistItems.list`를 50개씩 반복 호출해 전체 업로드 영상 ID 수집
4. `videos.list`로 실제 영상 제목/설명/게시일/썸네일 조회
5. `data/videos.json` 생성
6. GitHub Contents API로 기존 파일 SHA 조회 후 파일 교체
7. GitHub commit 생성 → 연결된 Cloudflare 배포 자동 시작

## 반드시 필요한 Worker Secret

- `YOUTUBE_API_KEY`
- `GITHUB_TOKEN`
- `ADMIN_TOKEN`

`ADMIN_TOKEN`은 직접 정한 긴 임의 문자열을 사용하세요.
예: 비밀번호 관리자가 생성한 32자 이상의 랜덤 문자열.

## 일반 Variables

- `GITHUB_OWNER=pilsaegyo`
- `GITHUB_REPO=pilsae`
- `GITHUB_BRANCH=main`
- `YOUTUBE_HANDLE=@pilsae`
- `ALLOWED_ORIGIN=https://pilsae.hyesung.workers.dev`

## 권장 Worker 이름

`pilsae-admin-api`

그러면 기본 주소는:
`https://pilsae-admin-api.hyesung.workers.dev`

사이트의 `site-config.json`도 이 주소를 기본값으로 사용합니다.

## 관리자 접속

공개 사이트 주소 뒤에:

`?admin=1`

예:
`https://pilsae.hyesung.workers.dev/?admin=1`

관리자 화면에서 `ADMIN_TOKEN`을 입력해 사용합니다.
토큰은 `sessionStorage`에만 저장되어 탭/브라우저 세션 종료 후 사라집니다.

## 날짜 분석

videos.json 자체는 YouTube 원본 제목/설명을 저장합니다.
날짜 판별은 기존 사이트 JS 규칙대로 화면 로드 시 description만 분석합니다.
해시태그 날짜는 제외합니다.

## 주의

- `YOUTUBE_API_KEY`, `GITHUB_TOKEN`, `ADMIN_TOKEN`은 절대 GitHub에 넣지 마세요.
- 세 Secret은 Cloudflare Worker Secret으로만 저장하세요.
- 별도 Worker를 새로 만들 경우 Secret은 Worker별 설정이므로 새 Worker에도 다시 등록해야 합니다.

## 채널 브랜딩 헤더 반영

- 채널 프로필 이미지는 원형 아바타로 자동 반영됩니다.
- `YouTube 영상 정보 업데이트`를 누르면 `data/videos.json`뿐 아니라 `site-config.json`의 `bannerImageUrl`, `profileImageUrl`, `channelTitle`도 함께 갱신됩니다.

## v7 통합 개선
- 혼합영상은 서로 다른 연도가 2개 이상일 때만 분류함. 같은 연도 내 여러 날짜는 해당 연도 영상으로 유지함.
- 같은 연도 날짜는 연도를 반복하지 않고 압축 표시하며, 많은 날짜는 `+N개`로 접어둠.
- 혼합영상은 먼저 연도 요약을 보여주고 세부 날짜를 펼쳐볼 수 있음.
- 혼합영상도 포함된 각 연도 필터 결과에 정상 노출됨.
- 제목/설명/출처/날짜 모두 검색 대상임.
- 활성 필터 칩과 개별 해제 기능 추가.
- 결과 영역에서 `전체 N개 · 현재 결과 N개`를 명확히 구분함.
- 모바일은 헤더 통계를 전체 영상 하나만 남기고 더 압축함.
- 관리자 화면에 날짜 미확인 영상 전용 검토 목록, 미확인 사유, 설명 미리보기, YouTube 원본 링크 추가.
- 실제 YouTube 설명을 OAuth로 수정하는 기능은 다음 단계로 보류함.

- 아카이브형은 각 영상을 대표 원본 날짜 기준으로 연도 → 월 순으로 묶어 보여줌.

- 날짜 더보기 버튼은 연도 요약과 별개로 실제 숨겨진 날짜 개수만 표시.

## v8.1 날짜 정확도별 아카이브 그룹화
- `day`: 정확한 날짜의 해당 월에 배치.
- `month`: 해당 월에 배치하고 `일자 미상` 표시.
- `year`: 1월로 넣지 않고 해당 연도 하단의 `연도만 확인` 영역에 배치.
- `unknown`: 전체 아카이브 마지막의 `날짜 미확인` 영역에 배치.
- 연도만 있는 영상은 내부적으로 YYYY-01-01을 저장해도 화면 그룹화는 `precision` 기준으로 처리하므로 1월 영상으로 오해되지 않음.

## v10 날짜 인식 개선
- `08.11.08`, `08-11-08`, `08/11/08` 같은 `YY.MM.DD` 형식을 정확한 날짜로 자동 인식.
- `9905` 같은 4자리 `YYMM`은 자동 적용하지 않음. 설명의 한 줄 맨 앞에 있고 MM이 01~12일 때만 관리자 `날짜 후보`로 제시.
- 관리자가 `1999.05로 적용`을 누르면 Worker가 GitHub `data/videos.json`에 수동 월 날짜를 저장하고 재배포.
- `날짜 아님`을 누르면 해당 후보를 제외 목록에 저장해 다음 동기화 이후에도 다시 제안하지 않음.
- 수동 적용 날짜와 제외 후보는 YouTube 전체 동기화 시에도 보존.


## v10.1 제목 + 설명 날짜 후보
- 날짜 미확인 영상에 한해 제목도 관리자 검토 후보 탐색에 사용.
- 제목 `08.11.08 ...` → `2008.11.08` 후보(자동 확정 아님).
- 제목 `081108 ...` → `2008.11.08` 후보.
- 제목 `9905 ...` → `1999.05` 후보.
- 설명의 `YY.MM.DD`는 기존처럼 자동 확정.
- 설명의 `YYMM` 4자리는 보수적으로 줄 맨 앞에서만 월 후보 생성.
- 관리자 화면에 `제목에서 발견` / `설명에서 발견` 배지 표시.
- 제목에서 나온 날짜는 반드시 관리자가 `적용`해야 실제 아카이브 날짜가 됨.


## v11 수동 날짜 + 플레이리스트
- 제목이 `2007 콘텐츠명`처럼 4자리 연도로 시작하면 `2007년` 후보로 처리. `2020.07`처럼 YYMM으로 오해하지 않음.
- 관리자 날짜 검토에서 날짜 후보가 없어도 직접 `2007`, `2007.05`, `2007.05.21` 형식으로 입력해 적용 가능.
- 콘텐츠 유형을 날짜 분류와 독립된 `일반 영상 / 플레이리스트`로 추가.
- 관리자에서 모든 영상을 검색해 플레이리스트로 지정/해제 가능.
- 연도가 있는 플레이리스트는 해당 연도/월 아카이브에도 표시되며 플레이리스트 필터로도 별도 탐색 가능.
- 날짜 없는 플레이리스트는 `날짜 미확인`이 아니라 아카이브의 `플레이리스트 > 연도 미지정`에 별도 표시.
- 전체 동기화 후에도 수동 날짜, 날짜 후보 제외 설정, 플레이리스트 지정이 유지됨.


## v12 다중 연도 + 플레이리스트 후보 축소
- 수동 날짜 입력에 `2007, 2006`처럼 여러 연도를 한 번에 입력 가능.
- 서로 다른 연도가 2개 이상 적용되면 자동으로 `혼합 연도` 분류.
- 기존의 `2007`, `2007.05`, `2007.05.21` 단일 입력도 그대로 지원.
- YouTube 동기화 시 영상 길이(`contentDetails.duration`)를 함께 저장.
- 플레이리스트 분류 관리 영역에는 `기존 플레이리스트` 또는 `6분 이상 영상`만 표시.
- 검색하지 않은 상태에서는 최대 30개까지만 보여주고 길이순으로 정리.


## v13 관리자 화면 개선
- `콘텐츠 분류`를 `날짜 검토`에서 분리해 독립 관리자 탭으로 이동.
- `?admin=1`로 들어오면 관리자 패널을 페이지 최상단으로 자동 이동하고 즉시 열도록 변경.
- 더 이상 공개 영상 목록 아래까지 스크롤할 필요 없음.
- 관리자 상단에 `일반 아카이브 보기` 바로가기 추가.
- 콘텐츠 분류 영역의 검색/설명/목록 배치를 정리해 버튼과 설명이 겹치지 않도록 개선.


## v14 다년도 플레이리스트
- 플레이리스트에 `다년도` 범위를 별도로 저장 가능.
- 날짜가 없어도 관리자가 `다년도로 지정`하면 `연도 미지정`/날짜 검토 대상에서 제외.
- 날짜가 실제로 2개 이상의 서로 다른 연도를 포함하는 플레이리스트도 자동으로 다년도 취급.
- 타임라인에 `플레이리스트 > 다년도 플레이리스트` 영역을 별도 표시.
- 진짜 연도를 정할 수 없는 전체 모음만 `플레이리스트 > 연도 미지정`에 남김.
- 관리자 날짜 검토 카운트에는 일반 영상의 날짜 미확인만 집계.
- 콘텐츠 분류 탭의 플레이리스트 항목에서 `다년도로 지정 / 연도 미지정` 선택 가능.
- 동기화 후에도 playlistScope 값 유지.


## v14.1 기존 날짜가 있는 다년도 플레이리스트
- 이미 `2001` 등 단일 날짜가 저장된 플레이리스트도 `다년도로 지정` 가능.
- `playlistScope = multi-year`가 기존 대표 날짜보다 우선하도록 변경.
- 따라서 기존 날짜를 삭제하지 않아도 타임라인에서는 `플레이리스트 > 다년도 플레이리스트`로 이동.
- 관리자 콘텐츠 분류 목록에서 기존 대표 날짜가 남아 있는 경우 참고용으로 표시.


## v14.2 콘텐츠 분류 버튼/UI 정리
- 관리자 `콘텐츠 분류` 탭에 아이콘 추가.
- `플레이리스트로 지정`, `다년도로 지정`, `연도 미지정`에 각각 독립 아이콘과 텍스트 표시.
- 기존 버튼들이 한 줄/좁은 열에서 겹치던 레이아웃을 카드별 하단 액션 영역으로 분리.
- 태블릿/모바일에서는 액션 영역을 영상 정보 아래 전체 너비로 이동.
- 작은 모바일에서는 다년도/연도 미지정 버튼을 자동으로 한 줄씩 배치.


## v14.3 수동 날짜 이후 설명 변경 감지
- 수동 날짜가 지정된 영상의 YouTube 설명이 수정되면 다음 API 동기화에서 변경을 감지.
- 기존 수동 날짜는 `previousManualDates`로 보관하고 활성 날짜에서 잠시 제외.
- 새 설명에 날짜가 있으면 그 날짜를 우선 표시.
- 새 설명에 날짜가 없으면 다시 `날짜 검토` 대상으로 이동.
- 관리자에서 이전 수동 날짜와 새 설명에서 인식된 날짜를 함께 확인 가능.
- `새 설명 날짜 사용` 버튼으로 새 설명 기준을 확정 가능.
- 새 수동 날짜를 다시 입력하면 검토 상태가 자동 해제됨.


## v14.4 콘텐츠 분류 목록 폭 개선
- 콘텐츠 분류 목록을 썸네일/영상정보/액션으로 다시 배치.
- 중간 화면에서는 액션 영역을 영상 정보 아래 전체 너비로 내려 겹침 방지.
- 넓은 화면에서는 우측 액션 영역을 420~520px까지 확보.
- `플레이리스트로 지정`, `다년도로 지정`, `연도 미지정` 버튼의 최소 폭을 확보하고 텍스트 줄바꿈 허용.
- 콘텐츠 분류 목록의 강제 높이/스크롤 제한을 제거해 좁은 박스 안에서 겹치지 않도록 개선.


## v14.5 다년도 플레이리스트 표시 수정
- `playlistScope = multi-year`인 플레이리스트가 카드/목록에서 `날짜 미확인` 또는 `날짜 확인 필요`로 표시되던 문제 수정.
- 날짜 값이 없어도 `다년도` + `여러 연도 수록`으로 표시.
- 날짜 유형 필터에서는 다년도 플레이리스트를 `혼합 연도` 쪽으로 취급하고 `날짜 미확인`에서는 제외.
- 연도 미지정 플레이리스트는 `연도 미지정`으로 별도 표시.


## v15 사용성 정리
- 공개 헤더 통계에서 `날짜 인식 / 확인 필요`를 제거하고 전체 영상 기록 수만 노출.
- 공개 검색 결과에서도 관리 성격의 `날짜 미확인 N개` 문구 제거.
- `?admin=1` 관리자 모드에서는 공개 검색/필터/영상 목록을 숨겨 전용 관리자 화면처럼 표시.
- 타임라인의 다년도/연도 미지정 플레이리스트를 하나의 `플레이리스트` 허브로 통합.
- 날짜 검토 탭에 `날짜 확인 필요 / 설명 변경 재검토`를 각각 카운트하고 0건일 때 완료 상태 표시.
- 카드/목록/연도·월 보기 전환 버튼에 텍스트 라벨을 추가하고 모바일 간격을 개선.


## v15.1 날짜 미확인 카운트/캐시 정리
- 공개 결과 상단에는 `전체 N개 · 현재 결과 N개`만 표시하고 `날짜 미확인 N개`는 완전히 제거.
- 다년도 플레이리스트의 실제 필터 분류(`혼합 연도`)와 raw 데이터 상태가 달라도 공개 카운트가 어긋나지 않도록 정리.
- `style.css?v=15.1`, `script.js?v=15.1`로 캐시 버스터를 추가해 모바일 브라우저가 예전 JS/CSS를 계속 쓰는 문제를 방지.
- `<body data-build="15.1">` 빌드 마커 추가.


## v16 찾기/탐색 사용성 개선
- 모바일에서 검색/필터 패널을 sticky로 고정해 목록을 내려본 뒤에도 바로 검색 가능.
- 검색어 2자 이상 입력 시 제목/출처/날짜 기반 자동제안 최대 6개 표시.
- 연도·월 보기의 연도 버튼에 해당 연도의 영상 수 표시.
- `플레이리스트` 빠른 진입 버튼과 플레이리스트 총 개수 표시.
- 카드 정보 순서를 `날짜 → 제목 → 출처` 중심으로 재정리.
- 플레이리스트 배지를 `플레이리스트 · 다년도`처럼 하나로 합쳐 배지 중복 감소.
- CSS/JS 캐시 버전 `v=16` 적용.


## v17 탐색 정리
- 메인 `플레이리스트 빠른 진입` 버튼 제거. 플레이리스트는 기존 `콘텐츠 유형` 필터에서만 선택.
- 검색창에 `×` 지우기 버튼 추가.
- 검색 자동제안에서 ↑/↓ 이동, Enter 선택, Esc 닫기 지원.
- 결과가 0개일 때 현재 검색/필터 조건을 보여주고 `검색·필터 초기화` 버튼 제공.
- 긴 목록 탐색 후 바로 위로 돌아갈 수 있도록 우측 하단 `↑` 버튼 추가.
- CSS/JS 캐시 버전 `v=17` 적용.


## v18 실험형 탐색 기능
- 별도 버튼을 늘리지 않고 카드의 `날짜` 자체를 클릭하면 같은 날짜 영상 검색.
- 카드의 `출처` 텍스트 자체를 클릭하면 같은 출처 영상 검색.
- 검색 중일 때만 `제목 일치 / 날짜 일치 / 출처 일치 / 설명 일치`를 작은 라벨로 표시.
- `연도·월` 보기에서만 각 연도 아래 월별 건수 칩 표시. 클릭하면 해당 월로 이동.
- 기존 기본 화면의 요소 수는 거의 늘리지 않는 방향으로 적용.
- CSS/JS 캐시 버전 `v=18`.
- 테스트 후 별로면 v17의 `index.html / script.js / style.css`로 바로 롤백 가능.


## v18.2 모바일 검색 자동제안 축약
- 실제 검색 결과 카드가 아니라 **검색 입력 중 표시되는 자동제안 목록**에 적용.
- 모바일에서 자동제안이 4개 이상이면 처음 3개만 표시.
- `N개 더보기`를 누르면 자동제안 드롭다운만 최대 52vh 높이로 확장되고 내부 스크롤로 탐색.
- `접기`를 누르면 다시 3개만 표시.
- PC에서는 기존처럼 자동제안 전체 표시.
- 실제 검색 결과 목록은 v18 방식 그대로 유지.
- CSS/JS 캐시 버전 `v=18.2`.
